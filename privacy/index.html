Privacy Policy

ZSpect operates 100% locally inside your browser. We do not collect, transmit, store on external servers, sell, or share any personal or browsing data.

1. Scope & Overview

ZSpect ("the Extension") is an open-source, client-side browser extension developed by Zane (@zane-tv) for inspecting user interfaces, measuring layout spacing, auditing WCAG accessibility contrast, saving UI design references, and generating local bug/feedback reports.

2. Zero Data Collection & Local-Only Storage

  • No External Servers or Telemetry: ZSpect makes zero network requests to any developer-controlled, analytics, tracking, or third-party server.
  • Local Preferences (chrome.storage.local): UI preferences—specifically Light/Dark theme selection, UI language (en / vi), and active session ID—are stored locally in your browser.
  • Local Workspace Database (IndexedDB): All inspection sessions, pins, cropped element screenshots, computed CSS/DOM snippets, and @ref design blueprints created by you are stored exclusively inside your local browser's IndexedDB (ZSpectDB).
  • User-Initiated Exports Only: Captured information leaves your browser only when you explicitly click to copy text/images to your system clipboard or download a report file (.xlsx, .zip, or .md) to your own device.

3. Automatic Secret & Credential Redaction

When recording 30-second diagnostic capsules (such as failed API calls or DOM excerpts) during an active inspection session initiated by you, ZSpect automatically redacts sensitive patterns—including Authorization headers, Bearer tokens, JSON Web Tokens (JWTs), API keys, cookies, sensitive URL query parameters, and input[type="password"] values—replacing them with [REDACTED] prior to local storage and export.

4. Browser Permissions Explained

  • activeTab & scripting: Used solely when you activate ZSpect (via toolbar icon, Alt+Z, or Side Panel) to mount the inspector HUD in a Closed Shadow DOM on the current webpage, leaving uninspected tabs untouched.
  • Host Permissions (<all_urls>): Required so developers and QA engineers can launch the inspector from the Side Panel, capture annotated element screenshots via captureVisibleTab, and compare UI components across localhost, staging servers, production domains, and reference websites.
  • sidePanel: Displays the docked ZSpect Workspace panel for reviewing pins, managing @ref items, and exporting reports.
  • offscreen: Crops high-DPI element screenshots and renders numbered pin badges in memory via OffscreenCanvas.
  • clipboardWrite: Writes annotated PNG screenshots or Markdown prompts to your clipboard only when you click a Copy action.
  • storage: Persists local theme and language settings.
  • debugger (Optional): Requested at runtime only when you explicitly toggle native :hover, :focus, or :active pseudo-class locking inside the Freeze tool.
