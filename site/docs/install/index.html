Installation

Install ZSpect in Chrome, Arc, Brave, or Microsoft Edge in under 30 seconds.

Option 1 — Chrome Web Store (Recommended)

Install ZSpect directly in Google Chrome, Arc, Brave, or Microsoft Edge with automatic updates:

Install from Chrome Web Store →

Option 2 — Download Prebuilt Release (.zip)

  1. 1.Download zspect-1.0.0-chrome.zip from GitHub Releases and unzip it to a local folder.
  2. 2.Open chrome://extensions (or edge://extensions / brave://extensions) and enable Developer mode in the top-right corner.
  3. 3.Click Load unpacked and select the unzipped folder.
  4. 4.Pin ZSpect to your browser toolbar and press Alt + Z on any http:// or https:// webpage.

Option 3 — Build from Source

Requires Node.js 20+ and npm:

Terminal 
git clone https://github.com/zane-tv/zspect.git
cd zspect
npm install
npm run build

Then load the generated .output/chrome-mv3 folder via Load unpacked in chrome://extensions.

Customizing Keyboard Shortcuts

You can customize ZSpect's global hotkeys anytime at chrome://extensions/shortcuts:

  • Alt+ZToggle ZSpect Inspector HUD — mounts HUD or switches between active and circular paused mode
  • Alt+Shift+FFreeze State Immediately — locks open tooltips/dropdowns without moving your mouse
