Frequently Asked Questions

Common questions about ZSpect permissions, frameworks, and privacy.

Does ZSpect slow down my browsing when I am not inspecting?

No. ZSpect uses programmatic runtime injection (registration: 'runtime'). Zero content scripts are loaded on any webpage until you explicitly press Alt + Z or click Inspect.

Why does ZSpect work on staging and third-party sites without installing an npm package?

Because ZSpect runs as a browser extension with a MAIN world probe and OffscreenCanvas screenshot pipeline, it inspects live DOM/Fiber trees directly in the browser—even on production builds or external reference websites.

Does ZSpect send screenshots or code to any external server?

Never. ZSpect has no backend server, no cloud database, and zero analytics. Every pin, screenshot blob, and @ref item stays inside your local browser's IndexedDB until you copy or download a file yourself.

Why does ZSpect cannot open on chrome://extensions or the Chrome Web Store?

All Chromium browsers restrict extensions from injecting scripts into internal chrome://, edge://, and Chrome Web Store pages for browser security. Switch to any http:// or https:// tab to use the HUD.
