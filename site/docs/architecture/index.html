Closed Shadow DOM & Focus-Trap Shielding

Injecting UI into arbitrary third-party websites requires strict isolation in both directions:

  • pxPure Pixel Token Scale — Uses --spacing: 4px inside a Closed ShadowRoot so host pages setting html { font-size: 10px } cannot shrink ZSpect's controls.
  • CSSInherited Property Reset — Resets scrollbar-color, letter-spacing, text-transform, and user-select at the :host boundary.
  • EventsModal Focus-Trap Shield — Stops bubble-phase propagation of keydown and focusin at the shadow host so Radix/MUI focus traps and host hotkeys never steal focus while typing notes.
