Privacy Policy

Effective Date: November 26, 2026 · 100% Local-First & Zero Telemetry.

ZSpect ("the Extension"), developed by Zane (@zane-tv), operates exclusively inside your local browser. We do not collect, transmit, store on external servers, sell, or share any personal data, browsing history, or website content.

Data Collection & Local Storage

  • ZeroNo External Transmission: ZSpect makes zero network requests to any developer-owned, analytics, advertising, or third-party server.
  • PrefsLocal Preferences (chrome.storage.local): Stores only your theme (light/dark), UI language (en/vi), and active session ID locally.
  • DBLocal Workspace (IndexedDB): All captured pins, cropped screenshots, DOM/CSS snippets, and @ref blueprints stay inside your browser's local ZSpectDB database.

Automatic Secret Redaction

When recording 30-second diagnostic capsules during an active inspection session, ZSpect automatically masks Authorization headers, Bearer tokens, JWTs, API keys, cookies, sensitive URL query parameters, and input[type="password"] fields with [REDACTED] before local storage and export.

Permissions Explained

activeTab and scripting mount the inspector HUD only when you activate ZSpect; <all_urls> allows capturing annotated element screenshots across localhost, staging, production, and reference domains; sidePanel renders the docked workspace; offscreen crops high-DPI PNGs in memory; clipboardWrite copies prompts/images on click; and optional debugger is requested only if you toggle native :hover/:focus locking.
