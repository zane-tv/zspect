Changelog

Release history and updates for ZSpect.

v1.0.0 — November 2026

Initial public release of ZSpect for Chrome, Arc, Brave, and Microsoft Edge.

  • NewUniversal on-demand Manifest V3 inspector (Alt + Z) with React, Vue, Svelte, Astro & Angular X-Ray and Cursor / VS Code / Windsurf deep-links.
  • NewCross-Tab @ref Design Vault for extracting DOM skeletons, CSS custom properties, motion rules, and Tailwind v4 hints.
  • NewVisBug visual toolkit (Redlines, WCAG 2.1 contrast, Spacing, Flexbox, Live Text, Design Overlay Diff) with Undo/Redo and Before → After diffs.
  • NewGhost-State Freeze (Alt + Shift + F), optional CDP pseudo-state lock, Web Animations scrubber, and 30s redacted Flight Capsule.
  • NewHigh-density Side Panel Workspace with Light/Dark themes, EN/VI localization, image clipboard, AI Prompt Compiler, and .xlsx / .zip / .md exports.
  • NewDraggable 38px HUD, inline hover-delete on screen pins, Clear All, and 44px circular logo pause mode.
